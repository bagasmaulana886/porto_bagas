# Portfolio — Bagas Maulana

Website portofolio pribadi **Bagas Maulana**, mahasiswa Program Studi Sistem Informasi di Universitas AMIKOM Yogyakarta.

## Fitur
- Tata letak editorial responsif dengan dukungan tema terang dan gelap
- Filter kategori karya (*Semua*, *Web App*, *UI/UX*, *Proyek Kampus*)
- Modal detail proyek dengan tautan repositori GitHub
- Formulir kontak dan salin alamat email cepat

## Struktur
- `index.html` — Struktur halaman utama
- `styles.css` — Desain dan tema warna
- `script.js` — Interaksi filter, modal, tema, dan formulir
- `assets/` — Aset gambar portofolio
